# ☀️ Sun Protector

ИИ-чат-бот по безопасности на солнце: риск по UV и типу кожи днём и ночью,
пеший маршрут в тени, советы про солнцезащитный крем по гайдлайнам WHO/AAD/EPA.

Пишите как в мессенджере: «можно выйти?», «проложи путь до …»,
«какой крем взять на пляж?». Не медицинский совет.

Код, архитектура и evals: https://github.com/kenzhe5/sun-protector
